# Ryn · 歌词盘 (Lyric Dial) concepts

Open `gallery.html`. Each `concept-N/index.html` is self-contained (shared `assets/common.js|css`, cover `assets/cover.png`).
Canvas 2D + requestAnimationFrame, 1280×800 logical stage (letterboxed to fit the window).
URL params: `?t=12.5` freezes at a time (used for screenshots); `?start=0` starts from the first line.
Lyrics are ORIGINAL placeholders; 12 lines, one every 3 s, transition easing ~0.9–1.1 s (easeInOutCubic; gauge needle uses easeOutBack).

Core model shared by all concepts: a continuous float `p` (line position) that holds on the current index and
eases to the next one at each line start. Every concept is just a different mapping `p -> geometry`.
In Godot: compute `p` in `_process`, call `queue_redraw()`, map in `_draw()`.

| 1 | 唱片沟槽 Vinyl | Record + grooves baked to a texture (or static `_draw` cached in a separate CanvasItem); label = `TextureRect` with circle mask shader, `rotation += delta*k`. Sheen = additive wedge sprite rotating. Needle tracks the song like a real record: needle radius r(t) = lerp(R_OUT 610, R_IN 178, t/duration), continuous; tonearm has a fixed pivot and length, tip = intersection of the arm's circle with the groove circle (closed form), arm angle = atan2(tip − pivot). Line i's groove = r((i+0.5)·lineDur), so the current line is always at the needle. Lyrics: upright horizontal `draw_string` per line placed on the arm's sweep at its groove (neighbours eased apart a little for air); no glyph rotation. On loop the arm glides back out over 1 s. Tonearm = `Sprite2D`/`Line2D`. | ~8 lines × ~15 glyphs ≈ 120 `draw_char` + few arcs. Cheap. |
| 2 | 星盘 Astrolabe | Each ring a `Node2D` whose `_draw` emits ticks once (cached); animate only `rotation`. Lyrics: one `draw_set_transform(pos, angle)` + `draw_string` per line (straight, tangent-rotated). Cover with circle mask shader. | Rings cost ~0 after caching (transform only); 5 `draw_string`/frame. Very cheap. |
| 3 | 仪表 Gauge | Dial face, progress ticks and radial labels redrawn only on line change (separate CanvasItem); needle = `Sprite2D`/`Polygon2D` with `rotation` driven by Tween `TRANS_BACK` (+ tiny jitter from `AudioEffectSpectrumAnalyzer`). Big line = 2 `Label`s cross-faded via `modulate.a`. | Per frame: 1 transform + 2 labels. Cheapest. |

| 7b | 光轮 II Luminous Planetary | Large dial (Ø680 band, centre x=200, partly off-screen). True planetary set: ring = the 6b engraved band (thin concentric rings, 24 quiet ticks, small Roman numerals I–XII, current numeral gold) with 48 coarse inner teeth (m 10, R 240) on its inner edge; sun Zs 24 (R 120) at the dial centre over the upright cover; three planets Zp 12 (R 60) on a carrier of radius 180. Zr = Zs + 2·Zp and (Zs+Zr)/3 = 24 → equal spacing meshes. Carrier is only a dotted hairline through the planet centres (no arms/bridges). Kinematics: ring θR = −p·15° drives (lyric arc; 12 lines = 180° = 24 teeth → seamless), sun nearly held (θS = π·Zp/Zs − 0.03·t), so the carrier — and the planets — visibly orbit: θC = (Zs·θS' + Zr·θR)/(Zs+Zr), i.e. 10° per line, gliding with the line easing, planets via external mesh with the sun `θp = ψ + π − π/Zp + (Zs/Zp)(ψ − θS)`. Cover fully clear at near-full brightness (only a light edge vignette); gears are luminous outlines only (no fill, no tint, no blur): teeth outline, one inner-rim circle, plain hub circle and 3 straight thin spokes. Lines: dark under-stroke + faint glow + hairline. No gear shadows (only a barely visible band shadow), small parallax, calm faint glint on the sun pitch circle (no mesh flashes), gold progress arc + gold index point + hairline at 3 o'clock, karaoke gold→white lyric arc. **Godot:** ring/sun/planet line-art + shadow textures baked once, per frame set 5 `rotation`s + 3 planet positions; numerals `draw_string` on the band (or baked into the ring texture with a separate gold label for the current one); cover is a plain TextureRect with a circle-mask shader; karaoke shader with `reveal` uniform. | ~9 sprites + 1 SubViewport + 2 small shaders; cheap. |

Notes: avoid changing font size every frame in Godot (each new size rasterizes glyphs) — prefer drawing at
the max size and scaling via `draw_set_transform`, or snap to a few sizes. Use MSDF fonts for crisp rotated/scaled text.
