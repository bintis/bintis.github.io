# Ryn · 歌词盘 (Lyric Dial) concepts

Open `gallery.html`. Each `concept-N/index.html` is self-contained (shared `assets/common.js|css`, cover `assets/cover.png`).
Canvas 2D + requestAnimationFrame, 1280×800 logical stage (letterboxed to fit the window).
URL params: `?t=12.5` freezes at a time (used for screenshots); `?start=0` starts from the first line.
Lyrics are ORIGINAL placeholders; 12 lines, one every 3 s, transition easing ~0.9–1.1 s (easeInOutCubic; gauge needle uses easeOutBack).

Core model shared by all concepts: a continuous float `p` (line position) that holds on the current index and
eases to the next one at each line start. Every concept is just a different mapping `p -> geometry`.
In Godot: compute `p` in `_process`, call `queue_redraw()`, map in `_draw()`.

| 7b | 光轮 II Luminous Train | Large dial (Ø652 band, centre x=200, partly off-screen). Rim = the 6b engraved band (Ø652): thin concentric rings, 24 quiet ticks and small Roman numerals I–XII engraved on it (current numeral gold), rotating with the song; its hidden-edge 48 inner teeth (m 10) drive the chain. Inside the dial only, a plain visible chain that meshes directly: Ring(48 int) → L(28) → M(16) → S(10), and L → S2(12). No carrier, no bridges, no arms; wheels are 5/4/3/3 tapered straight spokes. Arbor positions solved once at exact centre distances; angles: internal `θL = ψ − π/ZL − (Zr/ZL)(ψ − θR)`, external `θb = ψ + π − π/Zb + (Za/Zb)(ψ − θa)`. Ring = lyric arc (15°/line; 12 lines = 180° = 24 inner teeth → seamless loop). Cover under a light veil (blur 1.6px, ×0.67, cool multiply), crisp and full-bright inside the spoke windows (feathered mask). Lines: dark 3px under-stroke (legible over bright art) + 4px 7% glow + 0.7–1.1px hairline; rim > teeth > windows > dotted pitch circle. Soft blurred shadows, small parallax by depth, a slow, faint glint along two pitch circles (no mesh-point flashes), glass crescent + slow sweep, dust. Lyrics: concentric arc, karaoke gold→white reveal, gold index point + hairline connector + progress. **Godot:** 5 wheel textures + 5 shadow textures (bake offline), per frame set 5 `rotation`s; crisp windows = SubViewport mask (rotated window polygons) → cover shader `mix(veil, crisp, mask.r)`; karaoke = shader with `reveal` uniform on UV.x; comets `draw_arc`; dust GPUParticles2D. | ~10 sprites + 1 SubViewport + 2 small shaders; cheap. |

Notes: avoid changing font size every frame in Godot (each new size rasterizes glyphs) — prefer drawing at
the max size and scaling via `draw_set_transform`, or snap to a few sizes. Use MSDF fonts for crisp rotated/scaled text.
